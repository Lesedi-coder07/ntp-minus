# Notepad Minus

**Notepad Minus** is a minimal, local-first note-taking app designed to keep writers writing. Built for speed, clarity, and focus—no distractions, no cloud required, just you and your words.

## ✨ Features

- **Local-First Architecture**: Your notes are stored locally on your device. No cloud sync, no account required. Complete privacy and peace of mind.
- **Minimal Design**: Clean, distraction-free interface that gets out of your way and keeps you focused on writing.
- **Markdown Support**: Use familiar markdown formatting—bold, italic, headings—all at your fingertips with a simple toolbar.
- **Lightning Fast Search**: Instant search across all your notes with ⌘K (or Ctrl+K). Find anything in milliseconds.
- **Keyboard-Driven**: Masterful keyboard shortcuts for power users. Navigate, search, and format without touching the mouse.
- **Auto-Save**: Your notes save automatically as you type. No "save" buttons, no worrying about losing your work.
- **Open Source**: Built in the open. Contribute, fork, or customize to your heart's content.

## 🚀 Getting Started

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/ntp-minus.git
cd ntp-minus
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

### Usage

- **Create a new note**: Click the "+" button in the bottom bar
- **Search notes**: Press ⌘K (Mac) or Ctrl+K (Windows/Linux)
- **Edit title**: Click on the note title to edit
- **Format text**: Use the toolbar buttons for bold, italic, or headings
- **Switch between notes**: Use the search modal (⌘K) to navigate

## 🎨 Design Philosophy

Notepad Minus follows a minimalist design language:

- **Clean typography**: Inter font family for optimal readability
- **Soft colors**: Light grays, subtle blues, and plenty of white space
- **Minimal UI**: Only essential controls, hidden until needed
- **Smooth transitions**: 200ms transitions for a polished feel

## 🛠️ Tech Stack

- **Framework**: Next.js 15 with React
- **Styling**: Tailwind CSS with custom design tokens
- **Rich Text Editor**: Tiptap with StarterKit
- **Storage**: LocalStorage for persistence
- **Language**: TypeScript

## 🔐 Privacy

All your notes are stored locally in your browser's localStorage. Nothing is sent to any server, ever. Your notes stay on your device. Always.
